# Sales Analysis

Скрипт для обработки выгрузки заказов интернет-магазина и расчёта ежедневных показателей продаж по артикулам (SKU).

## Запуск

### Готовое приложение

1. Запустить `sales_analysis.exe`.
2. Указать путь к папке с исходным CSV-файлом. Путь можно скопировать из адресной строки Проводника.
3. Ввести название файла. Расширение `.csv` можно указывать или не указывать.
4. Дождаться завершения обработки.

Результат будет сохранён в той же папке под именем `daily_by_sku.csv`.

> **Важно:** если файл `daily_by_sku.csv` уже существует, он будет перезаписан.

### Запуск Python-скрипта

Требуется Python и библиотека `pandas`.

Установка зависимости:

```bash
pip install pandas
```

Запуск:

```bash
python main.py
```

Далее программа запросит путь к папке и название исходного CSV-файла.

## Обработка данных

В ходе предварительной проверки исходной выгрузки обнаружены следующие особенности:

| Проблема | Обработка |
|---|---|
| `order_date` считывался как `object` | Преобразован в `datetime` с помощью `pd.to_datetime()` |
| 4 пропуска в `quantity` | Все относятся к отменённым заказам. Оставлены без изменений, так как не влияют на выручку |
| 60 полных дубликатов строк | Удалены с помощью `drop_duplicates()` |
| Различия в регистре и лишние пробелы в `status` | Статусы приведены к нижнему регистру, пробелы удалены |
| Альтернативное написание `canceled` | Заменено на `cancelled` |
| Значения `price` и `quantity` | Проверены с помощью описательной статистики. Подозрительных значений, требующих дополнительной очистки, не обнаружено |
| Цены внутри SKU | Для каждого артикула минимальная и максимальная цены совпадают |

После удаления полных дубликатов все значения `order_id` оказались уникальными, поэтому дополнительная дедупликация по этому столбцу не потребовалась.

## Результат и контрольные проверки

Итоговый файл `daily_by_sku.csv` содержит следующие столбцы:

| Столбец | Описание |
|---|---|
| `sku` | Артикул товара |
| `order_date` | Дата заказа |
| `orders` | Количество уникальных заказов, включая отменённые |
| `revenue` | Выручка только по доставленным заказам |

Проверки корректности:

- Проверены типы данных и пропущенные значения.
- Проверено количество полных дубликатов.
- Проверена уникальность `order_id` после очистки.
- Проверена нормализация статусов.
- Сравнены минимальные и максимальные цены по каждому SKU.
- Выполнена независимая сверка итоговых количеств заказов и выручки с исходными данными.

**Контрольные показатели:**

| Показатель | Значение |
|---|---:|
| Заказов после очистки | 13 798 |
| Строк в итоговой таблице | 631 |
| Общая выручка | 10 276 540 ₽ |

## Ограничения

- Исходный файл должен быть в формате CSV с ожидаемой структурой и названиями столбцов.
- Результат всегда сохраняется под именем `daily_by_sku.csv` в папке с исходным файлом.
- При повторном запуске существующий файл результата перезаписывается.

Для запуска готового EXE-файла установка Python и дополнительных библиотек не требуется.
