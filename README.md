Как пользоваться:
1. Запускаем файл sales_analysis.exe
2. Когда появится сообщение: "Введите путь к папке с исходным файлом:"
Копируем туда путь к папке, где лежит файл, который нужно обработать. Можно скопировать из проводника путь в верхней строке
Пример:
D:\Projects\sales_analysis
3. Далее появится сообщение: "Введите название CSV-файла:"
Вводим название файла, с которым нужно провести анализ. Файл должен быть с раширением csv. При этом можно как указывать расширение в названии, так и не указывать
Пример:
Данные для тестового задания
4. Далее программа выполнит преобразования и сохранит файл "daily_by_sku.csc" в папке, которую указывали во 2 пункте


Обнаруженные проблемы в данных и их обработка:
1. Тип данных order_date. Изначально столбец считывался как object. Преобразован в datetime с использованием pd.to_datetime().
2. Пропущенные значения в quantity. Обнаружено 4 пропуска. Все они относятся к заказам со статусом cancelled, поэтому не влияют на расчёт выручки. Значения оставлены без изменений.
3. Полные дубликаты. Обнаружено 60 полностью идентичных строк. Удалены с помощью drop_duplicates().
4. Некорректные значения status. Обнаружены различия в регистре символов, лишние пробелы и альтернативный вариант написания canceled. Статусы нормализованы к значениям delivered и cancelled.
5. Числовые показатели price и quantity. Проведена проверка описательной статистики. Значения выглядят адекватно, оснований для дополнительной очистки не обнаружено.
6. Консистентность цен по SKU. Для каждого артикула минимальная и максимальная цены совпадают. Расхождений в ценах внутри одного SKU не обнаружено.
7. Значения order_id уникальны, так что дополнительной фильтрации не использовал
